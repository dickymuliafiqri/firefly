    A dead key never becomes an outage.
    
            
    Two counters that never touch: the keyring handles credentials, the breaker handles hosts.
    
            
    
              
    
                
    KeyRing
    
                
    429 → cooldown from Retry-After
    
                  401 → key retired
    
                  → next key, instantly
    
              
    
              
    
                
    Breaker
    
                
    5× host failures → open 10s
    
                  trial traffic → close
    
                  → fallback upstream

    Cut the bill, not the answer.
    
            
    Four optimizers inspect traffic before it leaves the gateway. Switched off, they cost nothing.

    compacts tool output — ANSI stripped, logs deduped, diffs folded
    
              
    caveman
    tells the model to skip the pleasantries
    
              
    ponytail
    biases code toward minimal diffs
    
              
    headroom
    prunes stale context from the middle
